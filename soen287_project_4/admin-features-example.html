How to Use:

  1. Add class admin-only to any element you want to hide from non-admins
  2. The initializeAdminFeatures() function runs on page load
  3. It checks user.isAdmin from localStorage
  4. If true, it shows all .admin-only elements
  5. Use isUserAdmin() function to check admin status in your code
